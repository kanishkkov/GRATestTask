# GRATestTask


A minimal Retrieval-Augmented Generation (RAG) assistant that answers questions about starting a business in Ohio using publicly available guidance from the Ohio Secretary of State.

The assistant retrieves relevant passages from official business guides, generates answers using a locally hosted language model, and provides document/page citations. When the available sources do not contain sufficient information, the assistant is designed to acknowledge that limitation rather than guess.

## 1. Setup and Usage

**Requirements:** Python 3.10+, [Ollama](https://ollama.com/download), and the dependencies in `requirements.txt`.

From the project directory, run:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

ollama pull qwen2.5:3b
python rag.py
```

Ollama must be running locally on `http://localhost:11434`. If the server is not already running, start it with `ollama serve` in a separate terminal.

The script loads the documents, builds an in-memory FAISS index, and starts an interactive command-line interface. Enter a question to receive an answer, or type `exit` to quit.

The first run may download the embedding model.

## 2. Documents and Models

**Source documents**

Two publicly available Ohio Secretary of State guides are used:

1. *Start a Limited Liability Company in Ohio* — [Ohio Secretary of State](https://www.ohiosos.gov/)
2. *Start a Sole Proprietorship in Ohio* — [Ohio Secretary of State](https://www.ohiosos.gov/)

Both PDFs are stored locally in the `documents/` directory as `llc.pdf` and `sole_proprietorship.pdf`. The documents contain information about business formation, registration, naming requirements, filing fees, and statutory agents.

**Models and libraries**

| Component | Technology | Purpose |
|---|---|---|
| Language | Python | Application implementation |
| PDF processing | PyMuPDF | Extract text with page metadata |
| Embeddings | `all-MiniLM-L6-v2` | Convert text into semantic vectors |
| Vector search | FAISS (`IndexFlatIP`) | Retrieve relevant document passages using cosine similarity |
| Language model | `qwen2.5:3b` via Ollama | Generate answers from retrieved context |

**Retrieval and generation**

1. Extract text from each PDF, preserving source filenames and page numbers.
2. Split text into 800-character chunks with 150-character overlap.
3. Exclude identified cover pages, introductory letters, and other non-substantive pages from indexing.
4. Generate normalized embeddings and store them in an in-memory FAISS index.
5. Retrieve the six most similar chunks for each question and combine overlapping passages from the same page.
6. Pass the retrieved context to Qwen 2.5 3B with instructions to answer only from the supplied evidence and cite its sources.

A minimum cosine-similarity threshold of 0.6 is used as a preliminary relevance filter. This is an experimental heuristic, not a reliable measure of answerability.

All model inference runs locally through Ollama; no paid API is required.

### Question 3: Does a sole proprietorship need to register with the Ohio Secretary of State?

**System answer:**

No, a sole proprietorship does not need to register with the Ohio Secretary of State. Ohio law does not require that a sole proprietorship must register with the Secretary of State (sole_proprietorship.pdf, page 9). However, if a sole proprietorship wishes to do business under a name different from that of the sole proprietor (personal name, i.e. Bob Smith), they must register a trade name or report the use of a fictitious name with the Secretary of State’s office (sole_proprietorship.pdf, page 6).

### Question 4: What is a statutory agent for an Ohio LLC?

**System answer:**

A statutory agent for an Ohio LLC is a person or corporation designated to accept legal process, notices, or entities that are served upon the company. The statutory agent must be one of the following: a natural person who is a resident of the state, a domestic or foreign corporation, nonprofit corporation, limited liability company, partnership, limited partnership, limited liability partnership, limited partnership association, professional association, business trust, or unincorporated nonprofit association with a business address in the state. The statutory agent must sign to accept the appointment (llc.pdf, page 10).

## 4. Limitations and Future Improvements

The prototype successfully demonstrates PDF ingestion, semantic retrieval, locally hosted language-model inference, source/page citations, and abstention when retrieved information is insufficient. However, retrieval similarity does not guarantee that a passage answers a question, and Qwen 2.5 3B sometimes combines unrelated requirements or incorrectly interprets general guidance as mandatory legal obligations. Citation validation checks source/page labels and formatting but does not verify factual support. The relevance threshold was chosen using a small number of test questions and may not generalize. With more time, I would evaluate a larger set of expert-reviewed questions, improve retrieval relevance and evidence diversity, add stronger claim-level citation verification, and test a more capable language model. The prototype is not intended for production legal or regulatory advice.
